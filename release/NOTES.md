**Which file is for which device**

- **Windows** (the counter): `Emporium-Build-@@BUILD@@-Windows-Setup.exe`. Download it and open it. It installs Emporium for you only (no administrator password) and puts it in the Start menu. To remove it: Settings, Apps, Installed apps, Emporium, Uninstall. The books stay.
- **Mac**: `Emporium-Build-@@BUILD@@-Mac-Apple-Silicon.zip` for an M1 or later, `Emporium-Build-@@BUILD@@-Mac-Intel.zip` for an Intel Mac (Apple menu, About This Mac, shows the chip). Unzip it, drag Emporium to Applications and open it. The first time, macOS refuses it: open System Settings, Privacy & Security, scroll down and choose Open Anyway for Emporium. You do this once.
- **iPhone and iPad**: `Emporium-Build-@@BUILD@@-iPhone-iPad.ipa`, one file for both. Install it with Sideloadly on a Mac or PC: connect the device with its cable, drag the file into Sideloadly, enter your Apple ID and press Start. Then, on the device: Settings, General, VPN & Device Management, trust your Apple ID; on iOS 16 or later also turn on Settings, Privacy & Security, Developer Mode. With a free Apple ID the app must be installed again every 7 days (as far as I know; Apple may change this).
- **Fire tablet**: `Emporium-Build-@@BUILD@@-Fire-Tablet.apk`. On the tablet, open this page in Silk, tap the file to download it, then open it. If the tablet asks, allow Silk to install unknown apps, then tap Install.
- **The standalone page**: `Emporium-Build-@@BUILD@@-Standalone-Page.zip`. Unzip it and double-click `Emporium.html`. Nothing is installed.

**If Windows warns you.** The installer is new and not signed with a paid certificate, so Windows may be cautious. If Edge says the file is not commonly downloaded: point at the download, click the three dots, then Keep, Show more and Keep anyway. If Windows shows "Windows protected your PC": click "More info", then "Run anyway".

**Good to know.** Each program keeps its own sealed books on its own device. A store set up in one place does not appear in another. To move a store, save a sealed backup in Settings and restore it on the other side.
