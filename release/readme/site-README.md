# Lakay on the web

**Build @@BUILD@@, @@DATE@@.** Lakay, the store's own app (inventory, the register and reports), as a web app:
**https://devgroup2313.github.io/lakay/**

- The address bar and the tabs show Lakay's logo, in any browser.
- **iPhone and iPad:** open it in Safari, press Share, then "Add to Home Screen". Lakay's logo goes on the home screen.
- **Mac:** open it in Safari, then File, "Add to Dock". Lakay's logo goes in the Dock.
- **Windows, Mac or Android with Chrome or Edge:** use "Install Lakay" in the address bar or the browser's menu.
- Once opened, it works with no connection.

**The books stay on each device.** Each browser, and each web app added to a home screen or the Dock, keeps its own
books, sealed with the store's password. Nothing is sent to this site or anywhere else. A web app added to an iPhone's
home screen keeps books apart from Safari's. Use one place for the store's books on each device, and keep a backup.

The ready-made apps for each device are in [Lakay-Windows](https://github.com/DevGroup2313/Lakay-Windows),
[Lakay-Mac](https://github.com/DevGroup2313/Lakay-Mac) and [Lakay-Apps](https://github.com/DevGroup2313/Lakay-Apps).
This site is made from Lakay-Windows by `release/device_repos.py web`.
