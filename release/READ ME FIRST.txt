TO OPEN IT
  Double-click Emporium.html. It opens in Microsoft Edge, Chrome or Safari.
  Nothing is installed, and nothing leaves the device.

THE FIRST TIME
  Press "Set up this store" and follow the five steps. Have a pen ready:
  the Master Key is shown only once. Write it down or print it, and keep it
  somewhere safe, away from the store's computers.

GOOD TO KNOW
  - The books are kept by the browser you opened the page with, on this
    device. Use the same browser each time.
  - Private (InPrivate or Incognito) windows forget everything when closed.
    Do not use them for Emporium.
  - Save a backup from Settings at closing time. The backup file is sealed:
    it opens only with your password or the Master Key.
  - The programs for Windows, Mac, iPhone and iPad, and the Fire tablet each
    keep their own books on their own device. A store set up in the browser
    does not appear in a program, nor the other way round. To move a store,
    save a sealed backup in Settings and restore it on the other side.

CHECKING THE FILE
  Emporium.html.sha256 holds the SHA-256 fingerprint of Emporium.html.
  On Windows (PowerShell):  Get-FileHash Emporium.html
  On a Mac (Terminal):      shasum -a 256 Emporium.html
